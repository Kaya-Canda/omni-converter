Privacy Policy

Zero Upload Guarantee: Whenever conversion is performed purely in-browser (for example image-to-image conversions), files remain on your device and are not transmitted to any external servers.

Server Conversion: For operations that require native ffmpeg capabilities (audio/video transcoding, GIF generation), your file is temporarily uploaded to the local server instance you run. The server performs the conversion and returns the converted file directly to your browser. Converted files and any temporary copies are deleted from the server's temporary storage immediately after the transfer completes.

Telemetry & Logs: Minimal session telemetry (timing and session length) is recorded to `user_logs.txt` only when you opt into server telemetry. No file contents, filenames, or extracted media are logged by default.

Third-Party Components: This application embeds third-party binaries (ffmpeg) and libraries. These components are executed locally on your machine. Review their licenses independently if required.

Privacy Controls: You can opt out of server-side telemetry by disabling it in the Settings tab or by not running the server. All data processed stays under your control when you run this software locally.
